# GymPlanner

Plánovač posilovacích tréninků pro iPhone a iPad.

## Kterou verzi použít?

| Máte Mac? | Verze | Složka |
|-----------|-------|--------|
| **Ne** (jen iPhone/iPad) | **Webová PWA** ✅ | [`GymPlannerWeb/`](GymPlannerWeb/) |
| **Ano** | Nativní SwiftUI app | [`GymPlanner/`](GymPlanner/) |

## Rychlý start (bez Macu)

1. Otevřete aplikaci na **GitHub Pages**:  
   **https://tomaspokornyi-del.github.io/gym-planner/**
2. Nebo postupujte podle [návodu pro iPhone/iPad](GymPlannerWeb/README.md)
3. Aplikaci si přidáte na plochu přes Safari → **Přidat na plochu**
